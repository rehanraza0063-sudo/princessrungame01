# Princess Run

A 3-lane endless runner in a single HTML file. An original princess runs from an original police officer. Includes background music, jump, dive, crash and coin sounds, and character voices (all generated in the browser with the Web Audio API, no audio files).

## Play
Open `index.html` in Chrome (or use Live Server in VS Code). No internet or backend needed.

## Controls
- Left / Right (A / D): change lane
- Up / W / Space: jump
- Down / S: dive (slide under bars)
- Touch: swipe, tap to start
- M: mute
